# DB-CW-3 — СТО (Станція технічного обслуговування)

## Зміст
- **RelDB.md** — логічна схема бази даних (Mermaid ER-діаграма)
- **RelTree.md** — дерево реляційної алгебри для прикладного запиту


У цій роботі виконано побудову логічної моделі бази даних для системи СТО, а також створено дерево реляційної алгебри для запиту, який відображає дані про замовлення, клієнтів і виконані роботи.
