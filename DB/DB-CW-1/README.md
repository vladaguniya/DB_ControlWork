# DB-CW-1 — СТО (Станція технічного обслуговування)


Діаграма Use Case для системи управління СТО.

У системі передбачено три типи користувачів:
- **Клієнт** — записується на обслуговування, переглядає історію, отримує сповіщення.
- **Майстер** — працює із замовленнями та відмічає виконання робіт.
- **Адміністратор** — керує персоналом, замовленнями та формує звіти.


- **UseCase.puml** — Use Case діаграма (PlantUML)
- **README.md** — опис користувачів і прецедентів
