# DB-CW-2 — СТО (Станція технічного обслуговування)

## Опис
UML-діаграма концептуальних класів для предметної області СТО.

У системі виділено такі основні класи:
- **Клієнт** — замовляє обслуговування, має контакти.
- **Автомобіль** — належить клієнту, має марку, модель, номер.
- **Замовлення** — описує конкретне звернення клієнта, містить перелік робіт.
- **Робота** — конкретна послуга або ремонт, що виконується майстром.
- **Майстер** — виконує роботи, має спеціалізацію.
- **Адміністратор** — керує персоналом і створює звіти.

Нижче наведена концептуальна діаграма (Mermaid):
classDiagram
%% --- Класи ---
class Клієнт {
  ім_я
  телефон
  email
}

class Автомобіль {
  номер
  марка
  модель
}

class Замовлення {
  дата
  статус
  сума
}

class Робота {
  назва
  вартість
  тривалість
}

class Майстер {
  ім_я
  спеціалізація
}

class Адміністратор {
  ім_я
  логін
}

%% --- Зв'язки ---
Клієнт "1" --> "1..*" Автомобіль : володіє
Клієнт "1" --> "1..*" Замовлення : оформляє
Замовлення "1" --> "1..*" Робота : містить
Майстер "1" --> "1..*" Робота : виконує
Адміністратор "1" --> "*" Майстер : керує
